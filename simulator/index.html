cyclOS simulator

this is a WASM based simulator for cyclOS.

Usage

Usage is very simple. compile cyclOS like usual, using wasm as the compilation target and simulator for the drivers. For example

tinygo build -o simulator.wasm -target=wasm

Do note that on windows, you need to install binaryen with:

scoop install binaryen

Then, upload your compiled binary into the WASM binary field in the setup section.

Finally, customize your simulated hardware to your liking before pressing Run.
